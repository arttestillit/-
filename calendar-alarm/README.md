# 出発アラーム（Android）

カレンダーの予定と時間割から **家を出る時刻を逆算** して、
**出発の50分前・40分前（変更可）にアラームを自動で鳴らす** Android アプリです。

Claude アプリから時計アプリにアラームを入れる方法では、
「1回だけのアラームは24時間以内しか設定できない」「会話を開いているときしかセットできない」ため、
毎日「明日のアラームセットして」と頼む必要がありました。
このアプリはスマホの中で自分でカレンダーを読み、**1週間先までずっと自動で** アラームをセットし直します。

## 計算のしかた

```
出発時刻 = 集合時刻 − 到着の余裕（10分） − 家からの移動時間（場所ごと）
アラーム = 出発時刻の 50分前 と 40分前
```

| 予定 | 移動 | 出発 | アラーム |
| --- | --- | --- | --- |
| 12:00 1217ファミマ | ファミマ 10分 | 11:40 | 10:50 / 11:00 |
| 火・水 1限 9:00 | 大学 60分 | 7:50 | 7:00 / 7:10 |
| 木 3限 12:55 | 大学 60分 | 11:45 | 10:55 / 11:05 |
| 金 4限 14:40 | 大学 60分 | 13:30 | 12:40 / 12:50 |

- **その日最初の外出だけ鳴らす**：授業のあとファミマへ直行する日（例：木曜の16時ファミマ）は2件目では鳴りません（設定でオフにできます）。
- **場所と移動時間**：予定のタイトルか場所に「ファミマ」「大学」などの言葉が入っていれば、その移動時間を使います。未登録の予定は既定の30分で計算し、一覧に ⚠ が出ます。
- **時間割**：カレンダーに入っていない授業を曜日・時刻・場所で登録できます。祝日（端末の祝日カレンダー）は自動で休みにします。
- **休講・休みの日**：一覧で予定のチェックを外すと、その回だけ鳴りません。最初の予定を外すと、その日の次の予定が「最初の外出」になります。
- 予定の追加・変更・削除は数秒〜1分で反映されます。再起動後や時刻変更後も自動でセットし直します。
- 鳴るとロック画面の上に全画面表示されます。**停止** か **スヌーズ** を選べます。止めるまで鳴り続け、10分で自動停止します。

初回起動時は、会話に出てきた内容（ファミマ10分・大学60分、火水1限・木3限・金4限）が入っています。
大学までの60分は、会話の時刻から逆算した値です。違っていたら画面で直してください。

## インストール

`app-debug.apk` をスマホで開いてインストールします（「提供元不明のアプリ」の許可が必要です）。

自分でビルドする場合は、Android Studio でこの `calendar-alarm/` フォルダを開いて ▶ 実行します。コマンドラインなら次のとおりです。

```sh
cd calendar-alarm
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 出発時刻・アラーム計算のテスト
```

## 初回の設定

1. 「カレンダー」と「通知」の許可ダイアログで **許可** を押します。
2. 画面上部に赤い警告が出たら、ボタンから設定を開いて許可します。
   - 「アラームとリマインダー」（Android 12）
   - 「全画面通知」（Android 14 以降）
3. **テストアラーム（10秒後）** を押し、画面を消して鳴るか確認します。
4. 一覧の出発時刻を見て、場所と移動時間を調整します。

### 鳴らないとき

- Xiaomi / OPPO / Huawei などは電池最適化が強めです。設定 → アプリ → 出発アラーム → バッテリー を「制限なし」にしてください。
- Googleカレンダーの予定が出ないときは、設定 → アカウント → Google で「カレンダー」の同期がオンになっているか確認してください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `AlarmPlanner.kt` | 予定・時間割・場所から出発時刻とアラーム時刻を計算する純粋ロジック（ユニットテスト対象） |
| `CalendarRepository.kt` | `CalendarContract` から予定（繰り返し展開済み・祝日判定つき）とカレンダー一覧を取得 |
| `AlarmScheduler.kt` | 計算結果と登録済みアラームの差分を取り、`AlarmManager.setAlarmClock` で登録・取消 |
| `AlarmReceiver.kt` / `AlarmNotifier.kt` | 鳴動時の全画面通知、停止・スヌーズ |
| `AlarmActivity.kt` | ロック画面の上に出す鳴動画面 |
| `SyncJobService.kt` | カレンダー変更の監視と1時間ごとの同期（JobScheduler） |
| `BootReceiver.kt` | 再起動・時刻変更後の再登録 |
| `MainActivity.kt` | 設定画面（予定一覧・場所・時間割・カレンダー） |
| `Prefs.kt` | 設定の保存と初期値 |

標準の時計アプリにはアラームを追加しません。アプリ自身がアラームとして鳴らします。
時計アプリのアラームは外部から確実に変更・削除できないため、予定が動いたときに古いアラームが残ってしまうからです。
