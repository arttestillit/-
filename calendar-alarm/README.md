# 予定アラーム（Android）

端末のカレンダー（Googleカレンダーなど、端末に同期されているもの）を読み取り、
**予定の開始◯分前に自動でアラームを鳴らす** Android アプリです。

## できること

- 予定の **何分前に鳴らすか** を選べる（開始時刻ちょうど〜120分前）
- 48時間先までの予定を自動でアラーム登録
  - 予定を追加・変更・削除すると数秒〜1分で自動反映（カレンダー変更を監視）
  - 1時間ごとの定期同期、再起動・時刻／タイムゾーン変更後も自動で登録し直す
- 繰り返し予定にも対応（1回ごとに鳴る）
- 同じ時刻の予定は1つのアラームにまとめる
- 対象外にできるもの
  - 終日予定（常に対象外）・キャンセルされた予定
  - 「不参加」にした予定（設定でオン／オフ）
  - カレンダー単位（仕事用だけ、など）
  - 予定ごと（一覧でチェックを外す）
- 鳴動時はロック画面の上に全画面表示。**停止** / **スヌーズ**（1〜15分）
- マナーモード中でも鳴るアラーム音量で再生し、止めるまで繰り返す（10分で自動停止）
- `setAlarmClock` を使うので Doze 中でも時刻どおりに鳴り、ステータスバーにアラームアイコンが出ます

## 動作環境

Android 9（API 28）以上。

## ビルドとインストール

Android Studio でこの `calendar-alarm/` フォルダを開いて ▶ 実行するのが一番簡単です。

コマンドラインの場合:

```sh
cd calendar-alarm
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk ができる
adb install app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # アラーム計算ロジックのテスト
```

## 初回起動時の設定

1. 「カレンダー」と「通知」の許可ダイアログで **許可**
2. 画面上部に赤い警告が出ていれば、ボタンから設定を開いて許可
   - 「アラームとリマインダー」（Android 12）
   - 「全画面通知」（Android 14 以降、ロック中に全画面表示するため）
3. **テストアラーム（10秒後）** で音が鳴るか確認（画面を消して試すと全画面表示も確認できます）

### 鳴らないときは

- 一部メーカー（Xiaomi / OPPO / Huawei など）は電池最適化が強く、バックグラウンド同期が止められることがあります。
  設定 → アプリ → 予定アラーム → 電池 を「制限なし」にしてください。
- Googleカレンダーの予定が出ない場合は、端末の 設定 → アカウント → Google → カレンダーの同期 がオンか確認してください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `AlarmPlanner.kt` | 予定一覧と設定から「いつ鳴らすか」を計算する純粋ロジック（ユニットテスト対象） |
| `CalendarRepository.kt` | `CalendarContract` から予定（繰り返し展開済み）とカレンダー一覧を取得 |
| `AlarmScheduler.kt` | 計算結果と登録済みアラームの差分を取り、`AlarmManager.setAlarmClock` で登録／取消 |
| `AlarmReceiver.kt` / `AlarmNotifier.kt` | 鳴動時の全画面通知、停止・スヌーズ |
| `AlarmActivity.kt` | ロック画面上の鳴動画面 |
| `SyncJobService.kt` | カレンダー変更の監視と定期同期（JobScheduler） |
| `BootReceiver.kt` | 再起動・時刻変更後の再登録 |
| `MainActivity.kt` | 設定画面・これからのアラーム一覧 |

標準の「時計」アプリのアラーム一覧には追加しません。アプリ自身がアラームとして鳴らします。
理由は、時計アプリのアラームは外部アプリから確実に変更・削除できず、予定が移動・削除されたときに古いアラームが残ってしまうためです。
