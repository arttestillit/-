# ナイトハイク記録アプリ (Android)

- 前景サービスで **画面消灯中も 1 分ごと** に GPS を記録(`TrackService.kt`)
- 地図: 国土地理院タイル / 道なりの線: OSRM 徒歩ルート(`routing.openstreetmap.de/routed-foot`)
- ルート入力: 「ルート設定」タブ → 地図タップで経路点・休憩所(☕)を追加
- 表示: 歩いた距離 / 残り距離 / 1時間ごとの平均速度 / 目標到着に対する%

## APK の入手
GitHub の Actions → "Build APK" → Artifacts の `nighthike-apk` をスマホにダウンロードして `app-debug.apk` をインストール(提供元不明アプリの許可が必要)。

## 使い方の注意
- 初回の「記録開始」で位置情報・通知・電池の最適化除外を **許可** してください(消灯中の記録に必要)。
- 山中で圏外でも記録は続き、電波が戻ると道路への吸着(マップマッチング)と地図が更新されます。地図タイルは事前に表示しておくと安心です。
