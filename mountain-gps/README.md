# オフライン山GPS

電波の届かない山の中でも、**事前にダウンロードした地図**の上に **GPSの現在地**を表示し、
**30秒ごとに位置を記録して軌跡**を描くスマホ向けWebアプリ（PWA）です。サーバー不要・アカウント不要。

## 機能

| 機能 | 内容 |
| --- | --- |
| 地図の事前ダウンロード | 画面に表示中の範囲（＋余白）を、指定したズーム範囲で端末に保存。地理院地図（標準・淡色・航空写真）/ OpenStreetMap |
| 現在地表示 | GPS（電波不要）で現在地・標高・精度を表示。地図を現在地に追従 |
| 軌跡記録 | 「記録開始」で **30秒ごと**（15秒〜10分で変更可）に位置を記録し、赤線で軌跡を描画。各点をタップで時刻・標高を表示 |
| 時刻表示 | 10分ごと（時計の 9:00, 9:10 …）に大きな二重丸の点を打ち、時刻を常に表示。縮小表示では時刻を隠す |
| ルート | 登る予定のルートを作成し、青い太線で常時表示。チェックポイント（山頂・休憩スポット・分岐点・絶景スポット）を配置できる。GPXの読み込み・書き出しも可 |
| 記録の保持 | 記録は端末内に保存。ページを閉じたり再読み込みしても記録は継続 |
| 軌跡一覧 | 距離・時間・累積標高（↑↓）を表示。地図に再表示、名前変更、削除 |
| GPX | 軌跡をGPXで書き出し（ヤマレコ・YAMAP・Googleマップ等で利用可）／GPXの読み込み（予定ルートの表示に） |

## 使い方

1. **登山前（電波のある場所で）**
   - スマホのブラウザでアプリを開き、「ホーム画面に追加」する
   - 位置情報の利用を許可する
   - 地図を登る山の範囲に合わせ、「地図DL」→「ダウンロード開始」
     - おすすめ：最小ズーム 10 / 最大ズーム 16（地理院地図は16で等高線・登山道がよく見える）
     - 1回の上限は 20,000 枚。広い場合は分けてダウンロード
   - 機内モードにして地図が表示されるか確認しておくと安心
   - 「ルート」→「＋ 新しいルートを作成」で予定ルートを描く
     - 「線を引く」：地図を道に沿ってタップして点を打つ（□はドラッグで移動・タップで削除、○で間に点を追加）
     - 「ポイント」：地図をタップして、山頂／休憩スポット／分岐点／絶景スポットを選んで配置
     - 「保存」で名前を付けて保存。保存したルートは地図に青い太線で表示される
2. **登山中**
   - 「● 記録開始」をタップ。すぐに始点が記録され、以後30秒ごとに記録
   - ◎ ボタンで現在地に戻る
   - 「■ 記録停止」で終了。終点が記録され、軌跡が保存される
3. **下山後**
   - 「軌跡」→「GPX保存」でファイルに書き出し

## 公開方法（HTTPSが必須）

GPS とオフライン機能（Service Worker）は HTTPS 上でしか動きません。
GitHub Pages を使う場合：リポジトリの Settings → Pages で公開ブランチを選び、
`https://<ユーザー名>.github.io/<リポジトリ名>/mountain-gps/` を開きます。

PCでの動作確認は `localhost` でも可能です：

```sh
cd mountain-gps
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 注意点

- **画面を消すと記録が止まることがあります。** ブラウザはバックグラウンドのページのGPSやタイマーを止めるため、
  画面OFF中の点は抜けることがあります（画面を点けた瞬間に1点記録して追いつきます）。
  確実に記録し続けるには、設定の「記録中は画面をスリープさせない」をON（既定）にして、画面の明るさを最小にしてください。
  バッテリー消費が増えるので、モバイルバッテリーの携行をおすすめします。
- 標高はGPSの値で、±10〜30m程度の誤差があります。
- ブラウザのデータ（サイトデータ）を消去すると、保存した地図と軌跡も消えます。大事な軌跡はGPXで書き出してください。
- iPhone の Safari では、ホーム画面に追加して使うとデータが消えにくくなります。
- 地図データの出典：[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)、© OpenStreetMap contributors。
  大量・高頻度のダウンロードはタイル提供元の負荷になるため、必要な範囲だけにしてください（OSMはズーム16まで）。
- 本アプリは登山の補助ツールです。紙の地図とコンパスも必ず携行してください。

## ファイル構成

```
mountain-gps/
├── index.html            画面
├── style.css             スタイル
├── app.js                地図・GPS・記録・ダウンロードの処理
├── routes.js             ルート・チェックポイントの作成と表示
├── sw.js                 Service Worker（オフライン対応・地図タイルのキャッシュ）
├── manifest.webmanifest  PWA設定
├── icon.svg              アイコン
└── vendor/leaflet/       地図ライブラリ Leaflet 1.9.4（オフラインで使うため同梱）
```
